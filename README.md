# AtCoder

AtCoderの問題に対する解答コードを管理するリポジトリです。

- **AtCoder Account:** [HK_Altair](https://atcoder.jp/users/HK_Altair)
- **Language:** C++

## Structure

```text
AtCoder/
├── ABC_○○○/
│   ├── A.cpp
│   ├── B.cpp
│   └── ...
├── ABC_△△△/
│   ├── A.cpp
│   ├── B.cpp
│   └── ...

```

各コンテストのフォルダに問題ごとの解答コードを保存しています。

また、各フォルダにコンテストの問題のミスポイントなどをまとめREADME.mdにまとめを行う。

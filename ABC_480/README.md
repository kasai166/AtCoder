# ABC 480 C -Self-Stopping Shower 


## 解法

青木君がボタンを押す時刻をソートし、隣り合う時刻の差から、お湯が途切れる区間があるかを判定する。

- 時刻 `0` から最初の操作時刻までの区間を考える。
- 隣り合う操作時刻の差が `K` 以下なら、追加操作は不要。
- 差が `K` より大きい場合、途切れる区間を埋めるために追加操作を行う。
- `T` 以上の操作時刻は除外し、終了時刻 `T` までを考える。

## ミスポイント

### 1. 切り上げ除算を忘れていた

```cpp
(x + K - 1) / K
```

### 2. 隣り合う時刻の差だけで計算していた

操作時刻の差が `K` 以下なら、前の操作で既にお湯が出ているため、追加操作は不要。

差が `K` より大きい場合、追加操作回数は次の式で求められる。

```cpp
(diff - 1) / K
```

ここで `diff = a[i] - a[i - 1]` とする。

### 3. 開始時刻 `0` の考慮漏れ

最初の操作時刻より前にも、お湯を出し続ける必要がある。

最初の操作時刻が `0` なら追加操作は不要。それ以外の場合は、時刻 `0` から最初の操作時刻までをカバーする回数を別途計算する。

```cpp
if (a[0] > 0) {
    ans += (a[0] - 1) / K + 1;
}
```

### 4. 終了時刻 `T` と範囲外の操作

`T` 以上の操作時刻を除外し、`T` を配列に追加することで、終了時刻までの区間を同じ方法で処理できる。

```cpp
a.erase(lower_bound(all(a), T), a.end());
a.push_back(T);
```

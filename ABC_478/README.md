# ABC 478 C - Sort Subarray

## 解法

1. 配列 `A` をコピーした `C` を作成し, `C` を昇順にソートする.
2. `A` と `C` を比較し, 値が異なる最初の位置 `l` と最後の位置 `r` を求める.
3. `l` が更新されなかった場合, すでに配列が昇順になっているため `Yes` を出力する.
4. `r - l + 1 <= K` なら, すべての不一致箇所を長さ `K` の区間に含められるため `Yes`, それ以外は `No` を出力する.

## ポイント

- **元の配列とソート後の配列を比較する**ことで, 変更が必要な範囲を特定できる.
- 長さ `K` の区間しかソートできないため, 最初と最後の不一致箇所の距離が重要になる.
- `rep1(i, N)` は `i = N` までループするため, `A[N]` にアクセスする危険がある. 配列の添字は `0` から `N-1` なので, 範囲外アクセスに注意する.
- `partial_sort` は一部の要素をソートする関数だが, 今回は区間の長さと不一致範囲を比較することで判定できるため, 使用する必要はない.

計算量はソートにより `O(N log N)`.
